# Project guidance

Read `DESIGN.md` before changing the interface. Preserve the paper-first flow: show one problem, ask the learner to work on paper, then collect only the final mathematical answer.

For UI work, apply the installed antislop core plus its UI, copywriting, human-accessibility, and mobile-layout skills. Keep every control functional, use no fabricated activity or statistics, retain visible keyboard focus, and verify mobile reflow and color contrast before delivery.

Math generators must be deterministic from their seed. Any new topic must supply a prompt, answer specification, worked solution, constraints, and tests across a large seed range.
