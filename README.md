# nurkh.

Paper-first algebra practice for college beginners. Work each question on paper, enter only the final answer, and receive an exact mathematical check.

Live site: [hafiz122.github.io/nurkh](https://hafiz122.github.io/nurkh/)

## Local development

```sh
npm install
npm run dev
```

Run the checks with `npm test`, `npm run test:e2e`, and `npm run build`.
